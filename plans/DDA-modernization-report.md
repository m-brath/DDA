## Findings

- **F0.1** Local ADDA build recipe established (now in `agents.md`):
  `NO_FORTRAN` (no gfortran on this Mac; only IGT/surface need Fortran — unused by the
  pipeline), FFTW3 from the conda env, manual relink with `-Wl,-rpath` (make cannot append
  LDFLAGS from the command line). Stale Linux `.d` files must be cleaned first.
- **F0.2** ADDA **1.2 vs 1.5.0-alpha3 produce identical results** (sphere case,
  `Qext` equal to 12 significant digits; same auto dipole density 160.664 dpl).
  → The 1.2→1.4/1.5 migration is low-risk for the *numerics*; the risk concentrates in
  option *validation* (e.g. rejected combinations) and output *formats*.
- **F0.3** Independent Mie validation (my scipy Riccati-Bessel helper, cross-validated
  against `miepython` 3.3.1, and B&H energy-conservation tests): ADDA deviates +1.7–2.2%
  on the tiny sphere at its *automatic* grid (2176 dipoles). Proven to be DDA
  discretization, not physics or conventions: forcing `-dpl 320/800` converges
  Qext 6.914e-3 → 6.852e-3 → 6.819e-3 toward Mie 6.793e-3. Baseline gate: `rel < 3e-2`
  in `check_baselines.py`.
- **F0.4** Convention trap discovered while writing the check: ADDA uses Im(m)>0 for
  absorption (e^{−ikr}); classical B&H-style helpers need the conjugated m. Documented in
  `check_baselines.py` docstring. Any future validation code must keep this straight.
- **F0.5** Deviation from plan: pipeline-level (Python) golden outputs could **not** be
  generated with the current stack, because the current numpy-2 env cannot even import the
  scripts (see Phase 1 §1.5). Baselines are therefore at the ADDA-binary level — which is
  actually the more robust reference (pure physics layer).
- **F0.6** ADDA 1.5.0-alpha3 built locally already (Phase 3 groundwork paid off early).

Key findings:

- **F1.1 Shape resolution scheme**: every size exists in **5 shape resolutions** with
  `frequency_min ∈ {192, 337, 457, 671, 887} GHz` (dipole count tied to fmin; N fixed per
  shape file — ADDA does *not* resample at higher f, it just rescales geometry; effective
  dpl therefore *grows* with f). Cost of a (size,f) job ⇒ set by the shape's
  `N_dipoles`, i.e. by the smallest resolution ≥ f/192 class.
- **F1.2 The three queued configs are test stubs** (single 5 GHz frequency) and
  **HexPlaAgg's current config (175.3 GHz) would not compute a single case** (below every
  fmin). Production frequency plans must be re-enabled/restructured before Phase 5 —
  plan a *frequency-class-aware* driver: for each f, use the shape resolution with
  `fmin ≤ f < next fmin` (this is already what `adda_main_control.py:135–158` skips toward).
- **F1.3 Size caps mostly work**: with `size_parameter_limit=10`, the HongPlate grid keeps
  1078 valid (size,f) pairs and excludes only 146 by x>10 (largest sizes at highest f).
  Note each of the 5 resolution files per physical size is a separate `shapelist` entry —
  the `f<fmin` skip logic already implements resolution selection:
  per frequency ≈31 physical sizes remain active.
- **F1.4 Estimated scale** (for Phase 4/5 planning): HongPlate grid = 1078 (size,f) pairs
  × 3 T = **3234 jobs**, each currently 5β × 10 incidence = 50 ADDA solves
  → ≈162k solves for one habit. The symmetry + incidence-angle optimizations (§1.6-1)
  dominate the cost picture.

## Decision: typhon.arts.xml replacement = pickle (not PyARTS)

- No `pyarts`/`arts` package on PyPI for any platform resolvable here; conda-forge has
  none (osx-arm64). `typhon==0.8.0` (last version with `ty.arts.xml`) **fails to import

## 4.2 Mueller-grid mirror transform — derived empirically (`analysis/phase4_grid_symmetry.py`)

For a particle mirror plane S and ADDA runs with propagation pair (p, S·p) on a
mirror-symmetric particle (oblate spheroid, **generic oblique p**, ADDA 1.2,
`-eps 3`), the relation between the two `mueller_scatgrids` was FITTED
(theta-map × phi-map × signed permutation over the 16 components):

| mirror (particle) | theta | phi map | component signs |
|---|---|---|---|
| XY (z→−z) | unchanged | φ → 180°−φ | outer(D,D), D=diag(1,1,−1,−1) |
| XZ (y→−y) | unchanged | φ → −φ | outer(D,D) |
| YZ (x→−x) | unchanged | φ → −φ | outer(D,D) |

- Residuals 2.9e-12 / 2.9e-13 / 2.9e-11 = solver noise; permutation is identity
  (signs only). Composing k mirrors: composed phi-maps, signs cancel for even k.
- ADDA's scat grid is propagation-**attached** — theta is never remapped.
- `ext_matrix` gets the same sign pattern elementwise (`mirror_signs(k).reshape(4,4)`).
- Cross-check: the legacy (never-executed) `construct_by_symmetry` uses exactly
  this convention (flip→−φ, XY adds +180° roll, M=[[+1,−1],[−1,+1]] blocks).
- Implemented as `acf.MIRROR_AXES / MIRROR_PHIMAP / MIRROR_D / mirror_signs() /
  mirror_phi_index_map()` in `adda_control_functions.py`.

## 4.5 Detector tool (`analysis/phase4_symmetry.py`)

Exact voxel-set mirror closure (bbox-centred flip + best integer translation,
row-void-set algebra — scales to 10^7 voxels) + geometric Cn test (rotate about
particle z, nearest-neighbour ≤ cubic covering radius √3/2, strict gate
score ≥ 0.999). Method traps found and fixed (all invalidated earlier tables):
random **subsampling breaks exact-closure** (a sample of a closed set is not
closed); `np.unique(a.view(np.void))` needs the **full-row itemsize** or it
silently de-duplicates scalar coordinates; coarse (<20-voxel) files cannot
resolve Cn; sampled KDTree dilutes Cn scores (cap raised to 3 M so production
habits stay un-diluted).

## 4.6 Measured habit symmetries (strict gate)

Two symmetry notions must be separated (**the shape model is a union of
cubes on a cubic lattice — its symmetry, not the ideal habit's, governs
what is exact**; noted by the user, verified by exact lattice tests):

- **mirrors** map the cubic lattice onto itself → voxel-set closure is
  exact-or-nothing and directly usable (it is what the pipeline exploits);
- **rotations by n≠2,4 about z do NOT map the lattice onto itself** — a
  voxelized hexagon can NEVER be an exactly C6 *model*; only C2/C4 about z
  (or compositions of exact mirrors) admit exact closure. `rot_score`
  measures the *ideal shape* at sub-voxel tolerance; using such a rotation
  for orientation reduction compares two DIFFERENT voxelizations of the same
  ideal habit, differing by an O(1-voxel) boundary layer → error at the
  discretization level, not free.

| habit | XY | XZ | YZ | C2z exact | C4z exact | ideal-shape Cn |
|---|---|---|---|---|---|---|
| HongPlate_Id9 (coarse→fine) | 1.000/1.000 | 1.000/1.000 | **0.986**/1.000 | 0.986/1.000 | 0.73/0.74 (never) | 6 (sub-voxel only) |
| HongPlate_Id9_TOR_sizegrid | 1.000/1.000 | 1.000/1.000 | 0.986/1.000 | (as Id9) | — | 6 (sub-voxel only) |
| HongColumn_Id7 | 0.986/1.000 | 0.957/0.996 | **1.000/1.000** | 0.957/0.996 | 0.43/0.00 | 2 |
| LiuSectorSnowflake_Id3 | 0.990/0.999 | 0.993/0.872 | 0.997/0.838 | 0.990/0.784 | 0.993/0.35 | 6-ish (sub-voxel only) |
| IconSnow_Id28 (fine, 5.17M) | 0.069 | 0.051 | 0.045 | n/a (mirrors already fail) | n/a | none |
| HexPlaAggCrystal_Id20 (fine, 14.6M) | 0.068 | 0.049 | 0.027 | n/a | n/a | none |

**Key finding 1: mirror closure is resolution-dependent.** The coarse
(192-GHz-class) voxel discretizations break closures that are exact at fine
resolution (HongPlate YZ 0.986, HongColumn XY/XZ). A filled mirror of a
NOT-closed voxel set is not a bug in the transform but a real shape error:
measured on HongPlate coarse YZ → `mueller` reldiff **1.5e-4**, `eps_vec` shift —
vs 4.5e-12 with exact closures. Production flags must use the closure of the
**coarsest** resolution class of the size grid.

**Key finding 2 (per above): even the *exact* rotation C2z is
resolution-dependent for the hex habits** (HongPlate 0.986 coarse — the
voxelized hexagon's orientation w.r.t. the lattice varies across the size
grid) → no production-size rotation reduction is available for HongPlate
either. Its XY+XZ fill-in does however already imply the exact C2x
(composition of the two enabled mirrors, closed under the fill subsets).

## 4b.1 Step 17 — β/incidence quadrature: NOT a lever (decision: no change)

Measured structure of the pipeline: **β and θ_inc are SSDB output coordinates,
not quadrature axes.** The ADDA solves run on the icosphere *vertex* set

- **Gauss–Legendre nodes on β / 0–90° incidence ranges change ZERO ADDA

## 6.2 Polarization-basis conventions (the phase-6 deep-dive)

Three separate convention facts had to be established before the gate
could pin the production one:

1. **The regular phase-matrix grid is LAB-absolute**, not incidence-frame:
   the phase4_hp_sym store (beta=0, theta_inc=90) shows its P11 peak at
   (theta_s=90, phi_s=0) = forward. Exact backscatter therefore sits at
   (theta_s = 180 - theta_inc, phi_s = 180). phi_s=0 comparisons (and any
   comparison at the singular point itself, where the PHI basis is
   degenerate) are wrong.
2. **Pointwise basis ladder**: the phase matrix P and the averaged Mueller
   M are related exactly by `P = R(-PHI2) M R(PHI1) * lambda^2/4pi^2`
   (`mueller2phase`, with `calculate_rotation_angles` PHI angles). At
   every phi_s=180 comparison point the ladder angles are multiples of
   180 deg, so both rotations reduce to identity there — the ladder was
   implemented in the gate (`phi_ladder`, validated against
   `calculate_rotation_angles` up to ±pi tester-ties, which are invisible
   to `rotater_mat`) and verified to be I at the comparison rows.
3. **Which ADDA pole column matches which side**: the scattering-plane
   normal `k_s x k_i` is +y_lab on the theta_s < 180-theta_inc side of the
   phi_s=180 ray, which is the continuous limit of the ADDA **Phi=0**
   column basis at the Theta=180 pole. The Phi=180 side carries the flipped
   basis (n = -y_lab) and must not be compared against the raw Phi=0
   slice. (An earlier gate revision compared the wrong side and produced
   O(1) errors for every convention — a good demonstration that the scan
   geometry matters as much as the convention.)

With 1-3 fixed, the convention scan (rotation-angle signs on both sides
plus constant Stokes conjugations) discriminates cleanly:

- `B_lab = R(phi_s) B_raw R(phi_i)` with the **ext-branch angle
  phi_s = -phi_i is wrong** (rel err vs the pipeline phase matrix 0.96 —
  sign-flipped off-diagonals). One-sided rotations score 1.85, wrongly
  paired constant conjugations >= 1.99.
- The correct transport is `phi_s = +phi_i`: the scattered basis of the
  back matrix is attached at **-v** (not +v like the ext branch), and
  parallel transport across the antipodal basis flip (hpol -> -hpol while
  vpol(-k) = vpol(k)) measures the angle with opposite sign — so its
  Stokes rotation enters with the opposite sign to the ext branch, i.e.
  `R(+phi_i)` on the left. Scan floor: 3.06e-2 max rel err (see below).
- **Ties at the floor** (deliberately tolerated by the gate, asserted as
  "production at the minimum, all distinguishable alternatives >= 5x
  worse"): `R(-phi_i)` on both sides (quadrature symmetry of the
  alpha/gamma average) and the constant conjugations D|D, T|T, DT|DT
  (this particle+geometry makes B insensitive to them: B11=B22, B33=B44,
  vanishing one-sided U couplings). The derivation picks +phi_i; nothing
  in the SSDB output distinguishes the floor-tie group.
- **Scan floor ~3%**: the production convention's max rel err at the
  comparison points is 3.06e-2 — and that number is NOT a back-matrix
  error term. Sources: (i) the comparison uses points 2-4 deg off the
  exact pole (the point itself is PHI-degenerate), and mueller2phase
  re-expands the averaged Mueller with eps_phase=0.001 *after* pole
  interpolation; (ii) `mueller2phase_core` pole-interpolates the
  off-diagonal spherical-harmonic expansions across the incidence-frame
  poles (`k % 5 != 0` branch) — near-pole off-diagonal values on the
  regular grid carry interpolation artifacts of a few %, and the
  coplanar-structurally-zero M13/M31 picks up ~1.2e-12 of fabricated
  value; (iii) at x=0.3 the ellipsoid backscatter structure varies on a
  degree scale near exactly the region probed. The gate therefore masks
  (1,3)/(3,1) at the coplanar comparison points (true value 0 on the
  back path by scattering-plane mirror symmetry — comparing the grid's
  fabricated value would test the known artifact, not the back matrix).
  **What pins the convention is the separation, not the absolute
  number**: every wrong family sits 31x above the floor (ext-analog
  phi_s=-phi_i: 0.961; one-sided: 1.845; mispaired conjugations: >=1.99),
  while the production entry and the physically-equivalent floor-tie
  group land at the artifact level. Gate 3's plate leg (x=0.024, much
  smoother, same interpolation machinery) closes the absolute-number
  question with a tight threshold.

GATE 1 (sphere) additionally confirms the raw extraction against Mie,
including the `diag(1,1,-1,-1)` structure that the attached-basis flip
between +v and -v produces *inside the raw values* — the extraction must
not add any extra D/T conjugation.

# Phase 8 — Size-parameter-adaptive scattering grid ✅ (2026-11-07)

Scope: replace the fixed 181x361 ADDA `-scat_grid` output grid with a grid
whose angular resolution scales with the size parameter x = pi*Dveq/lambda.
Motivation: at the small-x end of the size grid the fixed grid is grossly
oversampled (x=0.02 stores ntrunc~10 of an available 180), costing solve time
(scat-grid evaluation is part of every ADDA run) and I/O; at the same time
the export/SH machinery should eventually exploit the same band-limit. The
spherical-harmonic route itself is unchanged (SSDB stays SH coefficients).

## 8.1 Budget law (as implemented)

Two separate requirements, both physical:

- **phi / SH degree cap**: `ntrunc_cap = ceil(margin * (x + 4x^(1/3) + 2))`
  (`acf.scatgrid_ntrunc_cap`) — Wiscombe-style partial-wave band-limit times
  a Nyquist/safety margin. Calibrated default **margin = 6.0** (floor 8):
  the ACTUAL eps_sphexp=5e-3-limited stored ntrunc on the production static
  grid is 10 (x=0.02), 25-26 (x=0.5), 78-81 (x=5), 48 (x=10) — i.e. 3-6x the
  raw Wiscombe count, because the eps criterion measures the round-trip on
  the Gaussian-interpolated field and under-sees linear-interpolation error
  at the forward/attached-frame pole structure. margin 3-4 truncates the eps
  target at x~5 (observed relerr 1.2e-2 > 1e-2 gate), margin 6 passes
  everywhere.
- **theta resolution**: `ntheta = min(181, max(cap+2, ceil(pi*x/kappa)+1, 5))`
  with calibrated default **kappa = 0.1 rad** (angular features scale as
  1/x; kappa=0.17 would exactly reproduce the production 1° grid at the
  x=10 limit — 0.1 gives headroom). Uniform 0..180 range grid; the
  production grid stays the resolution ceiling.

Grid-file conventions (`acf.write_scat_grid_params`):

- **phi is a proper periodic RING, endpoint EXCLUDED** (max = 360-360/nphi).
  The historic static `scat_params.dat` (0..360 inclusive, 361 points)
  duplicates phi=0/360; on fine grids the shtns FFT tolerates it, on coarse
  grids the duplicate injects aliasing error ~dphi^2 — this produced a
  3.2e-2 rel-L2 twin mismatch at x=5 (per-element, M11/M16-dominant pattern)
  before the fix. phi=0 and phi=180 remain exact ring nodes.
- **nphi = 2*ntrunc_cap + 2 (EVEN)** so 360/nphi divides 180° and the
  Phase-4/6 mirror phi maps (phi -> -phi, 180-phi, 180+phi, see
  `MIRROR_PHIMAP`) map the ring exactly onto itself — `mirror_phi_index_map`
  otherwise raises (observed: 'phi grid cannot represent mirror XY, max dev
  4.39 deg' for the odd 2cap+1 ring).
- `spha.sph_expansion` initial truncation switched to
  **ntrunc = (nlons-1)//2** — required by shtns' `nphi > 2*mmax` rule for
  EVEN nlons; identical value (180) for the static 361-point grid, so the
  static path is untouched.

Gauss-node theta grids were tried (mode='gauss' kept in `acf` for
experiments only) and **rejected**: GL nodes lack near-pole samples and the
forward/backscatter-attached polarization-frame structure at theta=0/180 is
exactly what breaks — 0.48 rel-L2 on M34/M44 already at x=0.02, invariant in
ntrunc. Uniform theta is production.

## 9.3 Findings

1. **Model works where the eikonal validity conditions hold** (thin phase
   thickness, near-normal incidence): HongPlate **face** orientations at ALL
   x: |g|/|f| = 0.03–0.31, Cext_model/Cext_adda = 1.05–1.15, and full-eps
   ntrunc collapses 5→3, 10→3, 25→**6** (x=5!), 55→41. x10 t60 also wins
   big: 179 (grid-Nyquist-saturated) → 81.
2. **Model actively harmful at grazing/grazing incidence** (plate edge-on,
   t60 at x=5): |g|/|f| up to 1.73, Cext_model negative (−0.44×) — internal
   TIR + multiple scattering ignored by single-pass eikonal; |(m−1)k·chord|
   ≫ π. HC along-beam at x=5: phase thickness ≈ 8.6 rad, Cext_model = 0.16×,
   fitted |c| collapses (cdev 0.14) — model garbage there.
3. **Cell-level validity is measurable without the full field**: the fitted
   calibration magnitude |c_fit/c_global| deviates strongly exactly in the
   broken cells (dev > 1.4: x2 edge 5.2, x5 edge 6.4, x10 edge 4.0, HC x5
   along 0.14, HC x5 t60 2.0), and Cext_model ≤ 0 or < 0.5× flags them too.
   A per-solve validity gate is therefore cheap (the c-fit costs ms).
4. **Backscatter (θ=180) is NOT represented by the model** — |F_model(180)|
   vs ADDA's M11(180) ranges 1e-2 … 8.2 across cells (no consistent scale).
   Phase-6's separate `backMat_data` route (outside the SH expansion) stays
   mandatory; the hybrid would exempt the exact-backscatter ring as planned.
5. Summary gates as run: PASS G1 (all 7) + port check; FAIL residual-bounded
   (1.73 — driven entirely by the known-invalid orientations); FAIL ntrunc
   reduction under own-eps (2.105). Under the full-eps criterion 10/13 x≥2
   cells show reduction (0.24–0.96); all 3 losses are validity-broken cells.
   Gate code updated to report the full-eps criterion.
6. Side finding (recorded as code comment): the x=10 t60 FULL field already
   saturates ntrunc 179 ≈ the 361-φ-ring Nyquist cap 180 — production runs at
   x≈10 are grid-limited in SH space, which bounds any full-field comparison.

## 9.4 Verdict: **conditional GO** (gated hybrid), not universal

- The delta-scaling idea is **physically proven end-to-end** (conventions
  exact, model family validated, up to 4.2× ntrunc reduction and ~40×
  coefficient-count reduction at x=5 face; storage ∝ ntrunc²).
- A plain model-subtraction pipeline over all orientations would be **wrong**:
  ~1/3 of the scanned orientation space has the eikonal model harmful; the
  activation domain is x,orientation dependent and must be gated, not assumed.
- **9B design consequence**: per-(vertex,β) gate (cheap: c-fit + Cext_model>0
  + phase-thickness bound |(m−1)·k·chord_max| ≲ π) decides model+residual vs
  plain full field; hybrid stored like today for non-qualifying cells. The
  icosphere ARO vertex grid mixes both kinds per run — reconstruction in
  `rawdata2average` must know the per-cell flag (store in nc root/group attrs).
- **SSDB-hybrid decision: NO-GO for now** (as planned for 9A): the exported
  sph_coeffs are already capped (Phase 8.8, 15× smaller); the residual route
  additionally demands a format change + consumer cooperation. Internal
  (per-vertex caches + sub-control solve cost) is where 9B would pay: the
  ntrunc-179→81 class cells dominate the orientation-expansion refinement
  cost at large x.
- Cheaper alternative the scan also evidences: since face/near-face wins are
  largest where ntrunc_full is largest, a **pure adaptive-eps refinement
  re-balance** (no model) could capture part of the same cost — not
  investigated here (Phase-8 laws already exist); 9B should compare against
  that baseline before building the full hybrid.

## 10.4 Incident: `filter-repo` deleted the worktree copy — fully recovered

After the real run, `adda_shape_files/` on disk had collapsed to 8 KB (only `.DS_Store`):
**the 1.8 GB of geometry was gone from the working tree.** Cause, read from
`git_filter_repo.py` (`RepoFilter.run` → `cleanup`):

```python
#   If we need a reset, do a reset --hard
reset = not GitUtils.is_repository_bare(target_working_dir)
```

On a **non-bare** repo `filter-repo` ends with `git reset --hard` onto the rewritten HEAD.
The index still held the 1940 shape files (they were tracked at the old HEAD), the new HEAD
does not contain them → git removes them from disk. **`.gitignore` is irrelevant here**: it
never protects paths that are in the index. The `--no-checkout` dry run had an empty
worktree, so it could not surface this.

Recovery: `git fetch ../DDA-prepurge-2026-11-10.bundle refs/heads/main:refs/heads/prepurge-backup`
→ `git archive prepurge-backup adda_shape_files | tar -x -C .` → verified **1940/1940**
files hash (`git hash-object`) to exactly the blob SHAs recorded in the pre-purge tree
(0 mismatches), then the temporary ref was deleted and `gc --prune=now` re-run. Final state:
`.git` 44 MB, 1.8 GB / 1940 files on disk, `git status` clean.

**Rule for any future history rewrite: untrack the path first (`git rm -r --cached <path>`
+ commit) so the index no longer contains it, or run the filter in a *bare* clone and never
touch the worktree. Always take the bundle backup and verify byte-level recovery.**
Logged as Appendix D #29 in the manual.
